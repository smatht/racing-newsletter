# racing-newsletter

Template HTML para email de Racing Club de Avellaneda.

Diseño responsive con colores oficiales (azul #003087 y blanco).

## Secciones
- Header con escudo y branding Racing
- Estadísticas de la temporada
- Tabla de posiciones Liga Profesional
- Próximos partidos (Liga / Sudamericana / Copa Argentina)
- Últimos resultados con indicador G/E/P
- Noticias deportivas e institucionales
- Footer con redes sociales
